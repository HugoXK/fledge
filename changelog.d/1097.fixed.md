The nginx security-header gate now also refuses a `location` that declares an `add_header` of its own without repeating all four console headers with `always`. nginx stops inheriting the server-level set on such a path, so the sample's own documented trap could ship with every response from that location missing HSTS, `X-Content-Type-Options`, `Referrer-Policy` and `X-Frame-Options`; the deploy check now names the location block instead of printing a clean parse.
