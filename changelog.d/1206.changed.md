The action allowlist now carries `approved_unused`, a reviewed pre-approval for an action that is on the list while no workflow uses it yet, so the documented order — list entry first, workflow second — can be executed instead of failing in either direction. An entry names the issue that approved it and a minor release version by which it expires; the suite fails at that version and again when the exempted action is first used, and both messages name the entry, its issue and its expiry with the two legal moves: delete it, or renew it with a comment on the issue.
