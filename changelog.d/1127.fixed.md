The nightly release workflow no longer opts its own pull request into GitHub auto-merge. It still opens the mechanical release pull request and reports where it stands, but a person now performs the squash merge after `ci-ok`, `review-gate` and `pr-lint` pass on the tip, so a release can no longer merge with no review. A nightly that opens or reuses the pull request ends with the workflow green and the merge left to a maintainer.
