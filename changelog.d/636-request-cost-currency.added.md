Model cost is now recorded per request with the model, the provider currency and the price snapshot it was charged at, from a per-model price table (`PLATFORM_LLM_PRICE_TABLE`) with input, output and cached-input prices. Cached tokens are charged at the cached price instead of being billed twice, currencies are reported in separate buckets with no invented exchange rate, and a request that cannot be priced is recorded as unknown — never as a free call — with an audit entry and a lower-bound marker on the reported spend. The user quota, the per-job cost and the CNY repository budgets read USD-billed calls only, so a table priced in another currency is reported in its own bucket instead of being converted into the quota at an invented rate; a retry names the attempt it continues, so a retried retry keeps every attempt's spend.
