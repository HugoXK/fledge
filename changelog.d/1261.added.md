`npm run db:maintenance` plans or runs SQLite maintenance on the platform's own database. `--dry-run` prints the three steps it would run and executes none of them; a real run refuses unless `--backup` names the newest, intact copy inside the 26-hour window, refuses a locked database instead of waiting on it, records one `audit_log` row and writes a JSON report to `data/db-maintenance.json` — refusals included. `deploy/db-maintenance.cron.example` is a sample, and installing it is the owner's decision.
