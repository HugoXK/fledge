Model provider base URLs are now re-validated at use time, not only when saved. The gateway resolves a user-supplied provider host once per call, refuses the call when any answer is loopback, RFC1918, link-local/cloud-metadata, ULA, unspecified, multicast or otherwise outside the save-time policy, and pins the approved addresses into the connection so a DNS rebind between save and use cannot redirect the request. The refusal is terminal (no retry, no fallback), consumes no quota and does not echo the provider key or the resolved address.
