The account-deletion preview and the trial-purge paragraph in `docs/security.md` no longer state a fixed backup window ("local encrypted copies 30 days, GitHub 14"). Both now name the configured keep count: `BACKUP_KEEP_ENCRYPTED` (default 30) sets how many of the newest local encrypted copies per class the prune retains, so the sentence matches a policy that counts copies rather than days, and the GitHub-side number nobody configured is gone. The warning that a deletion does not erase backups is unchanged.
