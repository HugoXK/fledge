Operators can set `GATEWAY_TENANT_METERING=on` to publish `fledge_gateway_requests_total{tenant}` for each authenticated model-gateway request — once per user and once per repository for a repository token — and the gateway's two 429 answers gain `retryAt`, the epoch-millisecond time that address's bucket refills. The switch is off by default; with it off the limiter key, the window, the 429 body and the requests admitted are exactly what they were.
