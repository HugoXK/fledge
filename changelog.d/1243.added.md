`GET /api/v1/openapi.json` serves the token-authenticated API v1 as an OpenAPI 3.1 document, so a control room can generate a client instead of reading `docs/api.md` by hand. The document declares the bearer scheme, the four error envelopes (`invalid_api_key`, `insufficient_scope`, `rate_limited`, `invalid_cursor`) and the two shipped routes, and it needs no token because it names routes, not data. `test/openapi.test.ts` fails both ways — a `/api/v1/*` route the app registers but the contract omits, and a contract path with no route — so the contract cannot rot silently.
