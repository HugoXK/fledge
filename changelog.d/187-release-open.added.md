The daily release pull request is now opened by `scripts/release-open.mjs`, which verifies the pushed `release/v<next>` branch before it writes: it re-runs the version and changelog checks against the branch's contents fetched through the API instead of executing the branch's own copies, refuses when `main` moved since the plan or the diff leaves `CHANGELOG.md`, `changelog.d/`, `docker-compose.yml`, `package-lock.json` and `package.json`, and reuses an open pull request at the same commit rather than opening a second. It writes only that pull request and carries no tag endpoint; tagging stays with the nightly workflow.
