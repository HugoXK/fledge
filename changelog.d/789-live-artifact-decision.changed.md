A scheduled run now continues an open work item only when its artifact is still live: before the scheduler chooses a follow-up (or a review), it reads the item's pull request or issue once, and a merged pull request or closed issue turns that choice into a fresh iterate on the repository's own goal instead — the stale row is marked with the state that was observed, so the next tick does not choose it again. An open artifact, a failed read and an item that names no link all keep the previous behaviour, and a held-back repository costs no read.
