Fledge now removes a persisted `/data/bot/state.lock` before provisioning or restarting a FlyBot container. A container restart can reuse the same namespace PID, so a stale lock made the new DSH treat its own team as owned by another window and become read-only; removing the lock lets the restarted DSH create a fresh one. The health-driven auto-restart and model-apply restart both use the same path.
