A release now has one read-only status and one command to check it: `node scripts/verify-release.mjs --version X.Y.Z` reads the plan, release branch, pull request, annotated tag, image digest, SBOM, provenance attestation, GitHub Release and — with `--base-url` — the running `/healthz` back from the API and exits non-zero when any link is missing or disagrees. The same chain is rendered on `/admin` from the snapshot the command writes to `release-status.json`, and the publish workflow records the image reference, SBOM and attested digest in the release body so those links can be read back.
