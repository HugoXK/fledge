Superadmins can now export a read-only incident bundle for a 1h–24h window: `GET /admin/incident/<window>` returns JSON, `?format=markdown` returns the same artifact as markdown, and the admin metrics page links the 1h export. The bundle carries the release and build identity, schema version and counts, the readiness database/instance/clock/router readings, open alerts, recent job events, audit rows, the latest deployment and a config fingerprint of names only; every string is redacted and capped, and the window above 24h is refused. `npm run incident:bundle -- --db <copy.db>` prints the same artifact from a copy and refuses the configured live database.
