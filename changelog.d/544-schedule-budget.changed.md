A schedule can now carry a daily run limit. Set it on the schedule console ("daily run limit", empty = unbounded, the default). Before a due instant is dispatched the worker counts the instants already run for that schedule in the instant's own UTC day; at the limit the instant is recorded as skipped with the reason `budget-exceeded` instead of starting a job, and the console shows the limit, today's used count and what is left. A late or recovered run stays in the day it was scheduled for, so crossing midnight grants no fresh allowance. The limit is a run count, separate from the repository's CNY budget and the account quota, which still gate cost on their own.
