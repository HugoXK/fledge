The restore drill now refuses a copy that does not hold the application schema — the tables `users`, `repos` and `jobs` plus a positive `PRAGMA user_version` — whether or not a manifest is present, so `restore-drill: OK` can no longer describe a copy that holds no Fledge schema at all. A copy without a manifest now prints `manifest=missing` only after that check, so a refused run does not lead with the warning. A fresh instance with the schema and zero rows still restores.
