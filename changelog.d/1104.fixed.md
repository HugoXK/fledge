The exhausted-quota message on `/dashboard` and `/console` no longer tells an account that its jobs cannot continue when its repositories run on its own model. The platform quota only stops a repository the platform pays for, so the message now states that split — platform-model repositories pause, own-model repositories keep running — and links `/settings#model-providers`. An account whose repositories all run on its own model no longer sees the red error at all, which is what its own next action already said, while a mixed account — one own-model repository beside one the platform pays for — still sees it for the repository the quota pauses.
