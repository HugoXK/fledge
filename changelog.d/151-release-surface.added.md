The console now states which release it runs: every page's footer carries `v<version>` from `package.json`, and the `/admin` page has a release card with the running version, the newest `CHANGELOG.md` section and the count of pending `changelog.d` fragments. The card reads local files only — no GitHub call or token — and says "not available in this build" for a file the image does not carry, which is why the runtime stage now ships `CHANGELOG.md` and `changelog.d/`.
