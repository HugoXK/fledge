The schedule preview now runs at the time you pick. All four rhythm panels used to submit one `time` field, so the request carried four values, the server could not read the field, and every preview fell back to 09:00. Each panel now posts its own field (`daily_time`, `weekdays_time`, `weekly_time`, `monthly_time`), the mode-specific value wins, and the documented single `time` name still works for API callers.
