Each repository now has a development strategy that is versioned and content-addressed: a strategy page shows the bundle version and hash it is on with each section's source, and a maintainer can freeze the current strategy as a new candidate. A stale page is refused with both versions, and a strategy that names a frozen section — evaluator, evidence, CI, merge gate, auth, gateway or capability — is refused before anything is written; stable is never moved by freezing.
