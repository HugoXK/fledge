The evolution exporter can now score a held-out shadow run: `scripts/evolution-shadow.ts --shadow test/fixtures/shadow/holdout.json --record attempts.json --out report.json` runs the bundled mock runner over a checked-in, redacted fixture set and reports per-version success with Wilson intervals, Newcombe difference intervals, saturated tasks, cost and time, while `--attempts` replays a recorded run offline. A host that could push, merge or reach a live repository, an unredacted or empty fixture set, and a run that merged are refused instead of scored, and the report is an artifact a human reads rather than a PR comment.
