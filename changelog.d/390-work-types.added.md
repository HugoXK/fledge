Jobs now carry a work type — `iterate`, `triage`, `dependency`, `security`, `docs`, `performance`, `accessibility` or `migration` — with a declared contract for its stages, required evidence, risk tier, budget and whether its pull request may auto-merge, shown on the job page. The first new workflow is `triage`: it reads the open issues, ranks them by priority, links duplicates and proposes the next item, opens no branch or pull request, and the proposal becomes the work item the next scheduled session starts from. Triage rows are filterable on the dashboard, and a retried or resumed triage run stays a triage run instead of becoming an iterate job.
