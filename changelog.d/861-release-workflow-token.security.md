The release workflow no longer installs dependencies in the job that can publish. It now runs as a read-only `build` job that checks the tag out with `persist-credentials: false` and installs with `npm ci --ignore-scripts`, plus a `publish` job that checks nothing out, installs nothing, and only pushes and attests the image the build produced. A dependency's install script can no longer read a write-scoped token out of `.git/config`.
