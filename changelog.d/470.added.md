The admin metrics page draws the four series of its daily-trend table — jobs, succeeded, failed and merged — as compact inline sparklines above the table, each with its total as text and an `aria-label` for screen readers. The graphic is server-rendered SVG with no chart library and no external asset, it keeps the page free of horizontal scroll at 360, and a window with no daily data keeps the existing empty state rather than drawing a flat zero line.
