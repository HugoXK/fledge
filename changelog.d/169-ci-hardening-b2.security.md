The build now proves more before a merge: gitleaks scans the commit range for secrets, actionlint plus a template-injection checker lint the workflows, the container image is scanned for high and critical vulnerabilities and then started to check `/healthz`, the whole dependency graph is audited alongside the runtime set, and a measured line-coverage floor fails the build if coverage drops. A required job that reports `skipped` now fails the aggregate instead of passing it. Release images are published with a build-provenance attestation and an SBOM, which `gh attestation verify` checks. The required check set, with the up-to-date rule, is recorded in `.github/agent/required-checks.md`.
