Switching a repository to a new model provider now updates every role bot before Fledge reports success. If any bot is skipped or the update fails, `models_dirty` stays set, the failure is audited and the API returns `BOT_MODEL_ASSIGNMENT_FAILED` instead of a false success. Bot models are also reconciled after provisioning and immediately before job dispatch; a job is not sent to a team whose bots still point at the wrong provider.
