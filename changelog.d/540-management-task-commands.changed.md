The console's job commands now share one management contract. Run, plan, review, triage, work-item start/scope/verify, plan execute, resume and retry each carry the revision they rendered and an idempotency key, so a double submit queues one job and answers the same result, and a page rendered before someone else's write is refused instead of queueing a second job beside it. Each action writes a command receipt and bumps a revision in the same transaction as its audit row.
