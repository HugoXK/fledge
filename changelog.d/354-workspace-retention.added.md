Fledge now ships `scripts/artifact-retention.mjs` and `npm run artifacts:prune`, an operator tool that reports and reclaims the workspace snapshots each agent run leaves under `FLYBOT_INSTANCE_ROOT`. It is a dry run unless `--apply` is passed, keeps the newest `ARTIFACT_RETENTION_KEEP` snapshots and anything younger than `ARTIFACT_RETENTION_MAX_AGE_DAYS`, never removes a workspace that `state.json` or `inflight.json` names, and prints the candidates' bytes, the total and an audit line on every run. `docs/deploy.md` carries the policy and a timer example.
