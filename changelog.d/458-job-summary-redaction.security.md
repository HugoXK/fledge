Job summaries, errors, checkpoints and the issue/PR links a run reports no longer store a secret-shaped value. Redaction now runs before every truncation, so a cut cannot leave a token fragment behind, configured secrets (SMTP password, model key, session secret, webhook secret, bridge token) are replaced as literal values, both job writers apply it, and the job page, summary cell and admin jobs table redact again so a row written before this change no longer renders a raw token.
