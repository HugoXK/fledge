A release that was left half-made is now finished by the routine instead of by a human: when the tag exists but its GitHub Release does not, the tag job dispatches the publish run instead of skipping, and the scheduled slot repairs a merged release pull request whose tag is still missing. A tag that already has its release stays a no-op, a publish run that finds that release in place stops before it builds an image, and only the squash of the merged release pull request can trigger either write.
