The dashboard and the repository page now print the same next-run time, computed by the rule the worker uses. A repository with open work is due after the short work cooldown (15 minutes by default) rather than after its discovery interval, so a default 1440-minute repository no longer shows a run about 24 hours away while the scheduler is due in 15 minutes. The line also says why a run will not start: the repository is disabled, the FlyBot instance is not ready, auto-iteration is off, a job is running, there is no open work, or the scheduler has never run it.
