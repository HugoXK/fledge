`npm run evidence:ui` captures the before/after pair a user-visible console PR needs from one command. It builds the base and head in throwaway worktrees, seeds one shared fixture database, starts each app, signs in with the dev login, clicks every `--open` selector, screenshots the same selector at each locale and width, and writes `docs/images/<issue>/` on an `evidence/<issue>` branch with a ready-to-paste body table. It refuses a dirty worktree and a missing selector, never opens a pull request and never moves the tip; `--dry-run` prints the plan and `--push` pushes the evidence branch.
