A model selected for a repository now counts as an own model everywhere: the first-run checklist, the dashboard quota action, and the job enqueue and dispatch quota checks all use the same repository selection the gateway and bridge use. Adding a provider alone no longer marks the model step done — the step links to the repository picker until a model is selected — and a repository with a selected model can start a job after the platform quota is exhausted instead of being refused with `QUOTA_EXHAUSTED`. The first-run model step also shows the remaining platform balance: below `PLATFORM_QUOTA_COMFORT_CNY` (default 50) it warns that the balance may not cover the first run and recommends adding an own model now, while at or above it it only names the balance and where to configure a model later.
