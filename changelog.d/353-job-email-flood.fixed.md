A finished job no longer sends one email per run. Scheduled successes are carried by the daily summary, a failure that queued an automatic retry waits for the retry result, and failures for one repository are coalesced into one message per `JOB_EMAIL_COOLDOWN_MINUTES` (default 60). Settings gains an optional "email me when a scheduled job succeeds" switch, off by default, so existing users see no change; a manual run still mails its result.
