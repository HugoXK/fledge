A job now records the signed skill bundles it loaded — the team playbook and each repository skill — with the source, content hash and state of every bundle, and refuses to start when a bundle cannot be verified or its source is not on the repository allowlist. Revoking a source also blocks the automatic merge of a job that loaded it, while a maintainer's manual merge stays possible and is audited as an override; the repository page lists the set the latest job recorded.
