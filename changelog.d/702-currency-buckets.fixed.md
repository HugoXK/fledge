The cost-by-currency table on `/admin/metrics` shows each currency once again. `Store.costByCurrency()` grouped the ledger by the raw `currency` column and only labelled `NULL` as `USD` afterwards, so a row with no currency and a row billed `USD` came back as two buckets that both read "USD" — and every row an instance carries over from the pre-#636 schema has `currency NULL`, so the first deploy after an upgrade drew two `USD` rows. The label is now resolved before grouping (`GROUP BY COALESCE(currency, 'USD')`), which gives one `USD` row with the combined amount and call count; buckets in another currency, the unknown-request count and the lower-bound flag are unchanged, and the totals were already correct.
