The five highest-blast-radius browser mutations now carry a rate limit: sign-in, the admin role change, adding a repository, saving a rule override, and starting a job. Each names a class (login, destructive or expensive) with its own bucket and a configurable budget, and a refused request returns the bilingual "请求过多 / Too many requests" page instead of being processed. The other state-changing routes are unchanged and remain tracked on #708.
