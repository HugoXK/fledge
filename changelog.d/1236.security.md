`npm run rotate:drill` now proves a token rotation instead of assuming one: `--apply` mints a job token and an instance token in a throwaway database, uses both, revokes and replaces them, re-seals a bridge token, and fails unless the old values are refused and the replacements work. Each step writes one `rotation.drill.*` audit row, no token is printed, and the drill refuses production, the configured live database path and any path outside the temporary directory. The default dry run writes nothing.
