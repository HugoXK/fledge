The bundled shadow recorder in `npm run evolution:report` now reports an attempt it ran but could not verify as `missing` instead of `none`: a mock attempt opens a pull request and observes no check runs, so the recorded snapshot carries `ok: false` with that reason and the report's evidence column says "recorded, not verified" rather than "nothing was recorded". A `--record` run and its `--attempts` replay now print the same evidence counts, and an attempt that opened nothing still reads `none` because there was nothing to verify.
