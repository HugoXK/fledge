`node scripts/verify-release.mjs` now takes `--local-image-digest sha256:…` and reports the image this host would run as one more link (`local`), naming both digests when it is not the one the release and its attestation carry. The sample systemd unit runs the same verifier as `ExecStartPre=` against the recorded `/etc/fledge/release-status.json`, so a host whose recorded release is missing, unreadable or disagrees with the tree it starts does not start; the check is offline and needs no token, API call or docker.
