Superadmins get a product-loop page at `/admin/product`: how far connected repositories get (connected, first job, first PR, merged), the median time for each stage, how many runs a human had to rescue, which repositories came back a week later, and how complete a finished job's evidence is. The record behind it is an aggregate by construction — an event name, an instant, a duration and a salted repository fingerprint, with no column for a user, an account, a prompt, code, a token or a URL — so the same event from two different people is indistinguishable in the store. Analytics has its own off switch that writes nothing and mints no salt, a CSV export that answers only while it is on, and an optional operator-configured receiver that receives the page's counts at most once a day and never a fingerprint or an account.
