A missed release slot now leaves a record instead of an empty day: once the 02:00Z slot's grace window has passed, an hourly watchdog reads that UTC day's releases from the API and opens exactly one card naming the day, the expected slot, the grace window and the observed `daily-release` runs, with a marker that makes a rerun of the same day open nothing. The clock is the API `Date` header, not the host's, and the check is read-only otherwise.
