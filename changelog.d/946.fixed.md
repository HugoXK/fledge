A release target older than every tag in the repository is now refused as a target that predates the releases, instead of being planned as a first release. A repository that had already shipped `v1.20.0` would accept `v0.5.0` on an older commit and tag an old tree with a new name, because the first-release path skips both the "nothing to release" and "not higher" checks; the readiness page and the release form now print that refusal before anything is written. A repository with no tags at all still gets its genuine first release.
