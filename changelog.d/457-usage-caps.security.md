Repositories and FlyBot instances now have per-user ceilings: `LIMIT_REPOS_PER_USER` (default 10) and `LIMIT_INSTANCES_PER_USER` (default 3), plus an optional `LIMIT_INSTANCES_GLOBAL`. An add or provision beyond the ceiling is refused before anything is created, with the stable codes `REPO_LIMIT` / `INSTANCE_LIMIT`, a localized message naming used and cap, and an audited `limit.refused` row; the repository page shows the usage line. Admins are exempt, removing a repository releases its slot, and lowering a ceiling never touches content that already exists.
