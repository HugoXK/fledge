An approved account that never connects a repository now loses preview access by itself: an hourly sweep rejects it 7 days after registration, writes the `trial.expired` audit row the admin console already reads, and sends one bilingual notice naming the rule, the exemption for anyone who ever added a repository, and that an administrator can re-approve the account. The status change and the audit row commit together and the notice is sent afterwards, so the row is the record; the sweep is idempotent, never deletes an account or a repository, and can be run by an operator for one login or everyone, with `--dry-run`.
