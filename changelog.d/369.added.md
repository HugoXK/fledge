Each job now records a sealed context bundle: the compiled policy it ran under, content-addressed with SHA-256 and stored with the job. The job page shows the hash, whether the callback echoed the same hash back, and what changed against the previous job's bundle, field by field. A job whose stored bytes no longer hash to its recorded value is shown as unverified rather than as a passing record, so a hash that belongs to a different bundle can no longer be read as evidence.
