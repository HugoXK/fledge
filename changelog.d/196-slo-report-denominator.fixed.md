The SLO report no longer prints `NaN%` or `NaNm` for a quiet window: the four cells whose query can answer a non-finite number — job success rate, its error budget, the p95 queue wait and p95 job duration, and the bridge success rate — now render `n/a`, while the GitHub 429 rate and the open-alert count keep printing their real `0`. The same report and `docs/observability.md` now state what the success rate is a rate of: only `succeeded` and `failed` jobs are counted, so `cancelled`, `paused` and `quota_exhausted` are excluded from the numerator and the denominator alike, and the alert rule's selector is pinned to that same status set so the two cannot drift.
