A changelog fragment could put a line of its own at column 0 in the published release notes, so a crafted body could supply the `Image:` line the release verifier read as the chain — and a body that began a line `## [` silently cut the rest of the notes. Both render sites now publish a fragment as one paragraph, `changelog check` refuses a fragment that is not one, the verifier reads the chain block the publish job appends last instead of the first matching line anywhere in the body, and the publish run compares the digest it actually pushed, with an absent digest red instead of skipped.
