A repository page now answers whether it can be released before a version is typed. The read-only release-readiness view names the latest SemVer tag, the commits and merged pull requests since it with how many are features, and whether a `changelog.d` fragment is pending — or prints, in the same words the tag form refuses with, why a release would not go ahead. It creates no tag and no Release, and needs no release-scoped token.
