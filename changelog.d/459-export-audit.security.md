Admin CSV exports now record which filters produced the file, how far the export reached (`scope=all` or `scope=users:<n>`), the row count, and a SHA-256 of the exact response body, so a file found outside Fledge can be matched to its audit row. Searched text is recorded only as a length and an eight-character digest prefix, never verbatim, and the search page shows the newest export for the viewer's scope.
