A clock the platform had refused work for can now be re-measured by the scheduler itself: after the host clock is corrected the refusal lifts within five minutes, without a restart or an unrelated GitHub call, and a re-measurement that cannot reach GitHub keeps the refusal instead of clearing it. The refusal payload also records when the verdict was measured and how old it is, so a stale reading is no longer indistinguishable from a fresh one.
