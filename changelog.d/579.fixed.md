The `/admin` backup card now counts an encrypted copy (`fledge-<timestamp>.db.enc`) as a backup. With backup encryption enabled it reported no copy at all and told the operator to run `npm run db:backup` after every successful run, and an older plaintext copy in the same directory was shown as the newest while newer encrypted copies stayed invisible. The encrypted copy's age comes from its file-name stamp and its manifest's size and `sha256` are compared like any other copy's.
