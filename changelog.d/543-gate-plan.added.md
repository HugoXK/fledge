A repository now keeps a gate plan as a recorded proposal before anything is written: a closed schema names the four lanes (PR ready, PR merge, daily and release), their commands, observe flag, source and measured duration, and refuses an unknown field, lane, empty command, bad base SHA or oversize value. A maintainer can submit a plan through the read-only session API, read it back with a stable SHA-256 plan hash, and confirm it; confirmation records the actor and time and still writes nothing to the repository, leaving the gate pull request to a later slice.
