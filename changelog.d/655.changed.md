The console home now answers "what needs me now?" once per repository instead of once per account: a short queue lists each repository with exactly one thing to do — an answer, its most urgent alert, or its newest failed job, in that order — and a repository that needs nothing says when the platform runs there next and what it last produced, instead of leaving an empty widget. A failure in a repository outside the visible job table still reaches the queue, because the route reads each repository's own newest runs rather than the page slice.
