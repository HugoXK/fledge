The CodeQL gate now sees the class of result it exists to catch: `security-severity` is read whether the SARIF writes it as a number or a string, and rules that a query pack stores under `tool.extensions[].rules` are resolved by `ruleId` and `ruleIndex`. A security result whose severity cannot be read — and a result whose rule cannot be resolved — counts as high; a resolved quality query keeps its analysis level. The step also prints `parsed N result(s), H high/critical` beside every verdict and fails on an empty parse, so a blind gate can no longer look like a clean one.
