The CodeQL gate now sees the class of result it exists to catch: `security-severity` is read whether the SARIF writes it as a number or a string, rules that a query pack stores under `tool.extensions[].rules` are resolved by `ruleId` and `ruleIndex`, and an undeterminable severity counts as high instead of falling back to `level: warning` and medium. The step also prints `parsed N result(s), H high/critical` beside every verdict and fails on an empty parse, so a blind gate can no longer look like a clean one.
