A shadow run that crashed, timed out or failed to finish on a fixture expecting a refusal is no longer scored as a correct refusal. The refusal branch of the shadow scorer treated "opened nothing" as success, so a version that never completed a run could outrank one that ran and declined; an attempt that opened nothing but carries an error is now scored `reported-error`, which the report already counts as a failure. A clean decline (no pull request, no error) still scores the success the fixture asks for, and the pull-request branch is unchanged.
