The CodeQL gate now refuses a SARIF whose `runs` slot holds no run — a `null`, an array, a string, a number or a boolean — instead of reading it as a clean analysis with zero results. A truncated or reshaped SARIF fails closed with `run <n> is not an object`, a real analysis that legitimately found nothing still passes, and the existing no-run, malformed-JSON and missing-file refusals keep their wording.
