`GET /healthz` now names the build it runs: alongside `version` it reports `commit` (12-character short sha) and `builtAt` (UTC build timestamp), both always present and both `unknown` when the build carried no stamp. The values are stamped at build time from `GIT_SHA`/`BUILD_TIME` rather than read from `.git` at runtime, so a deploy can be identified from outside and two `main` builds inside one version range can be told apart.
