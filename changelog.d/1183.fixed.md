The nightly release opener no longer adopts an open pull request it never re-read. When a run finds the mechanical release pull request already open at the branch and commit from the plan, it now re-reads that pull request's head — the same `maintainer_can_modify` check it makes on a pull request it has just created — and refuses instead of answering `reused` when the head belongs to another repository, when the flag reads `true`, or when the readback cannot be made. The refusal names the pull request and the reason, so a red night says why on #80, and it never opens a second pull request on the same branch; a head that still checks out is reused as before.
