Repositories can now declare Fledge rules and text skills under `.fledge/` and `.agents/skills/`. Fledge reads them from the default branch at a fixed commit, records every file hash on the job, includes the rule text in the prompt, and serves a skill's full text on demand through a job-scoped context endpoint. A maintainer can also set a console override for each of the three rule files; the repository file still wins, the override applies only when that file is absent, and the job records which layer was effective. A pull request that changes a rule or skill file is flagged and blocks auto-merge until a maintainer acknowledges that head SHA.
