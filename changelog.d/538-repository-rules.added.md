Repositories can now declare Fledge rules and text skills under `.fledge/` and `.agents/skills/`. Fledge reads them from the default branch at a fixed commit, records every file hash on the job, includes the rule text in the prompt, and serves a skill's full text on demand through a job-scoped context endpoint. A pull request that changes a rule or skill file is flagged and blocks auto-merge until a maintainer acknowledges that head SHA.
