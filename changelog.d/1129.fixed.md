The job page's context-bundle card refused a bundle whose stored bytes no longer matched the recorded hash, and then printed, a few lines below the refusal, "The callback echoed the same hash." plus an unexplained field-by-field diff — because the echo sentence read only the callback's own claim about the run and the diff was built from the same bytes that had just failed verification. On the one surface whose job is to be unambiguous, a reader who skimmed saw a refusal followed by what sounded like confirmation. The echo sentence now names whose claim it is and says the stored bytes do not verify, the diff heading says it is read from bytes that did not verify, and a row whose stored bytes cannot be read at all says there is nothing to compare instead of claiming a first or identical bundle. When the bytes and the hash agree, the card keeps its original wording. Both languages carry the new sentences.
