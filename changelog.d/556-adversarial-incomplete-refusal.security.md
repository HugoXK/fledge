The independent adversarial review now refuses an automatic merge when it could not read the whole change: a diff cut at the size limit, a changed-file listing GitHub reports incomplete, or a changed file that arrives without a patch is recorded as incomplete and names the omitted files. A pull request whose unreadable files are all images or fonts under `public/` or `docs/` still merges and is recorded as read-only. Previously these shapes were recorded as skipped and the merge proceeded.
