Backup retention is now a policy the repository owns: `BACKUP_KEEP_PLAINTEXT` (default 1) and `BACKUP_KEEP_ENCRYPTED` (default 30) are read by the server and by the new `node scripts/backup-prune.mjs` dry run, which lists the copies beyond each class's count together with the manifest and `-wal`/`-shm` sidecars that belong to them, and deletes nothing. The `/admin` backup card shows the same count as "Expired copies: N (dry run)". No `--apply` mode ships here, so the first real deletion stays the owner's.
