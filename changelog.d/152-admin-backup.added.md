The admin console now shows the state of the database backups it has been running: the newest copy with its size and age, whether that copy's manifest still matches the file on disk, how many copies exist, and a warning when the schedule looks stale. It is read-only — no backup, restore or delete control — and it reports a missing backup, a copy with no manifest, and a copy whose manifest no longer matches as separate rows, so a stopped schedule and a bad copy cannot be mistaken for each other.
