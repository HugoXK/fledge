Review verdicts now take their identity from the platform object, not from a body line: a verdict submitted as a GitHub review is decided by the account that posted it, so the two-line `Written-by:` + `Author:` block is enough and `Posted-by:` is no longer required. A verdict posted as an issue comment remains valid only while the pull request has no review object at all and only until 2026-12-14; after that the gate refuses it and asks for a review.
