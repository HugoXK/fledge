The `deploy-check` sample contract no longer reports a rejection that named the header or the location as one that did not: its eight guards now test the captured text directly instead of piping it into `grep -q`, which exited at the first match and killed the producer with SIGPIPE, so `pipefail` turned a pass into a failure at large outputs. The checks and their messages are unchanged; only the way each one reads its own output is.
