The daily digest's next-run line now uses the same rule as the repository page and dashboard. A repository with a saved schedule row is answered by the planner, and a disabled, not-ready, idle, active-job or never-run repository prints the page's sentence instead of an interval time; a disabled repository with a saved row keeps the planner's instant. The email no longer promises a run that the page says will not start, and a cron repository no longer gets a different next-run time in the digest.
