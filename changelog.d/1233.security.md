`audit_log` now carries a SHA-256 hash chain: every new audit row commits to the row before it, `Store.audit` writes the link inside a savepoint, and `npm run audit:verify -- --db <copy.db>` walks a read-only copy and exits non-zero at the first edited, deleted or reordered row. Rows written before the chain are reported as unverified, never forged, and the verifier prints the chain start and the number of hashed rows.
