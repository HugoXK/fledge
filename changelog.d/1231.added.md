`/admin/metrics` now carries a read-only SQLite health card: file size, freelist, the largest tables and the slowest statements, with the newest slow query and the configured `SLOW_QUERY_MS` threshold. Every Store read and write is timed into `fledge_db_query_seconds{statement}`, labelled by verb and table (for example `select:jobs`) and never by SQL text or a parameter; a statement above the threshold enters a bounded 20-entry in-process ring. The card and the Prometheus series read the same names, and the card's own table counts do not fill the ring.
