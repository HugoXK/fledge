# 0001 — Name: Fledge (羽巢)

- Status: accepted
- Date: 2026-10-29
- Decision owner: HugoXK

## Context

The product hosts GitHub repositories and lets a FlyBot agent iterate on them
continuously. It needs a name that is:

1. short and pronounceable in Chinese and English;
2. tied to **growth / iteration**, not to a generic "AI code" tool;
3. compatible with the FlyBot bird metaphor without copying FlyBot's own
   `/evolve` product name;
4. plausible as a `.dev` / `.app` domain and a GitHub repository;
5. not a descriptive compound that is hard to say (`RepoIterator`, `SelfCode`).

The repository is `HugoXK/fledge`.

## Candidates

| Name | Meaning | Strength | Risk |
|---|---|---|---|
| **Fledge** | A young bird grows flight feathers and leaves the nest | Verb, bird metaphor, exactly "become able to fly on your own"; matches FlyBot | An accelerator uses the word; `fledge.app` is registered |
| Roost | A place where birds settle for the night | Short, calm, hosting metaphor | Suggests rest/passivity, not iteration; `roost` is used by rental products |
| Trellis | A frame that supports a growing plant | Growth + support, calm | Less tied to birds/agents; common in gardening and software |
| Itera | From "iterate" | Direct, brandable | Generic; many consultancies use it; no host/place meaning |
| RepoLoop | Repo + loop | Obvious | Descriptive, clunky, hard to trademark |

## Decision

**Fledge** (Chinese: **羽巢**).

- Tagline: **"Hosted repositories that grow themselves."**
- Chinese tagline: **"让仓库自己长大。"**
- The product verb: *fledge a repo* — connect it, give it a goal, let it grow
  under review.
- Visual language: a feather/wing mark, not a robot. The letter **F** is drawn as
  a wing.
- Working domain: `fledge.dev` (no DNS record at the time of the check; verify
  before a public launch). Fallbacks: `getfledge.dev`, `fledge.run`.
- If a trademark conflict appears, the first fallback is **Roost**, because the
  code and docs already use a "hosted nest" metaphor.

## Consequences

- The UI copy uses bird/growth language sparingly: *fledge*, *nest*, *flight*,
  not in every sentence.
- The platform never claims the repository is "autonomous": the promise is
  **reviewable growth**, one PR at a time.
- The name does not encode "GitHub" or "AI", so the platform can later support
  GitLab or other agents without a rename.
