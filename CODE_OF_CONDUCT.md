# Code of conduct

Be direct, be kind, assume good faith.

- Discuss ideas, not people.
- No harassment, discrimination, or personal attacks.
- Respect privacy: never post someone's tokens, email, private repository or
  conversation.
- Security reports go to the address in [SECURITY.md](SECURITY.md), not a public
  thread.
- Maintainers may edit or remove content that breaks these rules and may block
  accounts that repeat the behaviour.

If you see a problem, email `hugo2001xk@gmail.com`. Reports are handled
confidentially.
